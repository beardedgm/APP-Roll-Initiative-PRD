# Web Lurker
*Creature 3*

ne, medium, aberration

---

**Perception** +10; darkvision, {@ability tremorsense} 30 feet (imprecise)

**Languages** aklo; spider speak

**Skills** Acrobatics +9, Athletics +9, Crafting +8, Stealth +11

**Recall Knowledge - Aberration** (Occultism): DC 18

**STR** +4, **DEX** +4, **CON** +3, **INT** +1, **WIS** +3, **CHA** -1

**Spider Speak** The web lurker can speak with spiders, with the same effects and limitations as speak with animals.

---

**AC** 19

**Fort** +10, **Ref** +11, **Will** +8

**HP** 45

**Spring upon Prey** ◈ **Trigger** A creature touches the web lurker's web while the web lurker is on it.; Requirement Initiative has not yet been rolled. The web lurker automatically notices the creature and Strides or Climbs before rolling initiative.

---

Speed 25 feet, climb 25 feet

**Melee** ◆ fangs +11/+6/+1 (poison); **Damage** 1d8+6 piercing plus web lurker venom plus web lurker venom

**Melee** ◆ claw +11/+7/+3 (agile); **Damage** 1d8+6 slashing

**Melee** ◆ web +11/+6/+1; plus web trap

**Web Lurker Venom** (poison)

**Web Trap** A creature hit by the web lurker's web attack is immobilized and stuck to the nearest surface until it succeeds at DC 20 Acrobatics check to Escape.
